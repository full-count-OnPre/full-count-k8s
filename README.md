# full-count-k8s

쿠버네티스 매니페스트 저장소입니다.

현재 디렉터리 역할:

- `app/`: 애플리케이션 워크로드
- `sre-monitoring/`: 모니터링, 부하테스트, 운영 문서

목표 namespace 구조:

- `app`
- `data`
- `db`
- `monitoring`

현재는 기존 모니터링 자산이 `sre-monitoring/` 아래에 있고, 신규 애플리케이션 매니페스트는 `app/` 아래에 추가하는 방식으로 정리합니다. 디렉터리 대이동은 보류하고, 워크로드가 늘어날 때 `app/`, `data/`, `db/` 를 점진적으로 채우는 방향을 기준으로 삼습니다.
